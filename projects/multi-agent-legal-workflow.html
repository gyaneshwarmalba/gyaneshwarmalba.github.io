Multi-Agent Legal Workflow

LangGraph orchestration for legal processes

An orchestrator routes each request to specialist agents for contract review, compliance checks, and summarization, with human review checkpoints before anything is finalized.

View on GitHub

The problem

Legal requests are rarely one step. A single contract question can involve reading the agreement, checking it against policy, looking up related records, and summarizing the outcome for a stakeholder. One general-purpose prompt handles this poorly; a workflow of focused agents with clear hand-offs and review points handles it far better.

Architecture

  1. User or triggerA request from a person or an event in a business system
  2. Orchestrator graphLangGraph routes the request and tracks state across steps
  3. Specialist agentsReview, compliance, and summarization agents, each with a narrow job
  4. Tools and APIsAgents call approved tools such as document search and record lookups
  5. ReviewA human checkpoint approves, edits, or sends work back

Key design decisions

  • Explicit graph over free-form agents. LangGraph makes routing, retries, and state visible and testable instead of hidden in prompts.
  • Narrow specialist agents. Smaller, focused agents are easier to evaluate and improve than one agent that does everything.
  • Human checkpoints at decision points. The workflow pauses for review wherever the output carries legal or business risk.
  • Traceability. Each step is traced (LangSmith) so reviewers and engineers can see how a result was produced.

Tech stack
