Multi-Agent Legal Workflow

Specialist agents with a deterministic supervisor and a human approval gate

A LangGraph supervisor sends each contract through review, compliance, and summary agents, then pauses for a human when risk is high. State is checkpointed, so a paused review can be approved from a different process hours later.

View on GitHub

The problem

Legal requests are rarely one step. A single contract question can involve reading the agreement, checking it against policy, and summarizing the outcome for a stakeholder. One general-purpose prompt handles this poorly; a workflow of focused agents with clear hand-offs and review points handles it far better.

Architecture

  1. IntakeParse the contract into numbered clauses; reject text with no clause structure
  2. SupervisorA pure routing function of the current state picks the next agent, so every path is reproducible
  3. Review agentParties, effective date, term, renewal, obligations, and notice periods, each tied to a section number
  4. Compliance agentVersioned policy checks: liability cap, mutual damages exclusion, no unilateral termination, data use, 72-hour breach notice, payment terms, governing law
  5. Summary agentExecutive summary built only from upstream outputs
  6. Human approvalLangGraph interrupt() pauses high-risk runs; Command(resume=...) continues them with the reviewer's decision

Key design decisions

  • A deterministic supervisor, not LLM routing. Legal workflows need reproducible paths and a clear audit trail. LLMs are used where they help: extraction and prose.
  • Compliance verdicts are rules; explanations can be generated. The approval gate depends on pass or fail, so that result must be repeatable for the same contract and policy version.
  • Validate model output and fall back. LLM extraction must return JSON with the expected keys; otherwise the rule-based extractor is used and the fallback is recorded.
  • Escalate instead of crashing. Transient Bedrock errors are retried with backoff. Any other agent error is recorded and the run is routed to a human.
  • One framework. LangGraph alone covers routing, interrupts, retries, and checkpointing, so CrewAI was dropped from the original plan.

Run it

git clone https://github.com/gyaneshwarmalba/multi-agent-legal-workflow.git
cd multi-agent-legal-workflow
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app/main.py
python -m app.cli run data/sample_contracts/acme_master_services_agreement.txt
python -m app.cli resume <thread_id> --reject --reviewer alice
pytest

On the synthetic samples, the one-sided MSA fails 8 checks and pauses for approval; the NDA and SaaS agreement are auto-approved.

Status

Working demo with 17 automated tests running in CI, including pausing and resuming a workflow across separate processes. The rule-based agents run offline. Bedrock mode is switched on through configuration and has not yet been validated against a live account.
