AI Legal Contract Analyzer

Governed RAG pipeline for legal documents

Splits contracts into their real clauses, answers questions with section citations that are checked in code, scores risk against versioned rules, and publishes nothing until a reviewer approves it.

View on GitHub

The problem

Legal teams spend a lot of time reading long agreements to find specific clauses, spot risky language, and check terms against policy. Generic chat tools are a poor fit: answers need to cite the source text, stay inside approved models and data boundaries, and leave the final call to a human reviewer.

Architecture

  1. Clause-aware ingestionSplits on the contract's own headings (1. TERM, Section 4, ARTICLE III), so every chunk is a real clause and every citation is a section number
  2. Embed and indexLocal hashing embedder offline, or Amazon Titan embeddings; in-memory or FAISS index
  3. Retrieve and generateTop-k clauses go to an extractive generator offline, or Claude on AWS Bedrock with a citation-only prompt
  4. Citation checkAnswers that cite nothing, or cite a clause that wasn't retrieved, are marked ungrounded and sent to review
  5. Risk scoringVersioned JSON rules (liability caps, one-sided indemnity, auto-renewal, data use, and more), each with evidence and a recommended fallback position
  6. Human review, then publishOnly approved reviews are written to local JSON or a Salesforce custom object

Key design decisions

  • Citations are enforced in code, not just requested in the prompt. The pipeline verifies every [n] against the retrieved clauses and routes failures to a person.
  • An extractive baseline that can't hallucinate. Offline mode only quotes retrieved text, which makes it a control when comparing a hosted model against the same retrieval results.
  • Rules decide risk; models explain it. Deterministic rules give repeatable, auditable scores, and every report records the policy version it was scored against.
  • No path to Salesforce without a reviewer. The sink is only called from the approval decision.
  • Fits existing workflows. Approved results land where legal teams already work, in Salesforce, rather than in a separate tool.

Run it

git clone https://github.com/gyaneshwarmalba/ai-legal-contract-analyzer.git
cd ai-legal-contract-analyzer
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload       # API docs at localhost:8000/docs
streamlit run ui/streamlit_app.py   # reviewer UI
pytest

No API keys needed. Three synthetic contracts (an MSA, an NDA, and a SaaS agreement) are loaded automatically.

Status

Working demo with 25 automated tests running in CI. The offline path runs end to end. The Bedrock, FAISS, and Salesforce adapters are switched on through configuration and have not yet been validated against live accounts. Known limits: the offline embedder is lexical, indexes are rebuilt at startup, and the risk rules are tuned to the sample contracts.
