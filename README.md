# gyaneshwarmalba.github.io

> Portfolio Website — Gyaneshwar Malba | AI Solutions Architect

## Overview

Personal portfolio website showcasing AI/ML projects, technical blog posts, and professional experience at the intersection of AI, Salesforce, and Cloud.

## Live Site

[https://gyaneshwarmalba.github.io](https://gyaneshwarmalba.github.io)

## Features

- Professional profile and bio
- Project showcase with a write-up page per project
- Resume download and certifications
- Contact via email and LinkedIn

## Structure

| Path | Purpose |
|------|---------|
| `index.html` | Home page: profile, projects, certifications, contact |
| `projects/*.html` | One write-up page per project |
| `styles.css` | Shared styles for every page |
| `site.js` | Builds email links at runtime and sets the footer year |
| `assets/` | Resume PDF and other static files |
| `404.html` | Shown by GitHub Pages for unknown URLs |

To add a project, copy one of the files in `projects/`, edit its content, and add a card for it in `index.html`.

## Tech Stack

- HTML5 / CSS3 / JavaScript (no build step)
- GitHub Pages

## Setup

```bash
git clone https://github.com/gyaneshwarmalba/gyaneshwarmalba.github.io.git
cd gyaneshwarmalba.github.io
# Open index.html in your browser
```
